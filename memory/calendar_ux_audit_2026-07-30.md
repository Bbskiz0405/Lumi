# 行事曆完整產品健檢（2026-07-30）

## 檢查方式

從一般使用者的完整流程檢查「建立 → 查看 → 修改／改期 → 提醒 → 重複 → 找回 → 同步 → 刪除／復原」，而不是只核對既有按鈕是否能按。比較來源以官方說明為主：

- Google Calendar：日／多日／月／Schedule 視圖、搜尋、重複事件與任務。
- Apple Calendar：開始／結束、地點、提醒、跨日、複製，以及日／週拖曳改期。
- Outlook：行程／會議、重複、提醒、忙碌狀態與分類。
- Fantastical：自然語句、任務／行程切換、範本與從時間格快速建立。

## 結論

Lumi 已有可用的月曆、單日議程、任務、原生行程與手機日曆橋接，但目前比較像「月曆上附帶資料清單」，尚未完整支援使用者安排時間的連續流程。最大差距不是再增加一種內容，而是時間輸入、跨日／重複、快速改期、搜尋與同步可信度。

## P0：資料與信任

1. **完成任務仍殘留在手機日曆**
   - 原因：完成狀態會更新任務，但同步層仍把它當普通全天 event 更新。
   - 決策：完成時刪除 Lumi 產生的手機日曆 event；取消完成時依設定重新建立。
   - 狀態：v0.4.71 已修。

2. **同步失敗不可見**
   - Lumi 行程先存本機，再 best-effort 寫入手機日曆；失敗只記 console。
   - 使用者可能以為 Google 已有資料。
   - v0.4.71 第一階段：行程卡顯示「已寫入手機日曆／僅儲存在 Lumi」，外部日曆讀取失敗顯示可重試提示。
   - 後續：資料表加入 pending／synced／failed 與最後錯誤，提供單筆重試。

3. **外部刪除或修改後，Lumi link 可能過期**
   - 目前 Lumi 是本機資料權威；手機日曆裡手動修改 Lumi event 不會回寫。
   - 若手機端刪除，external event ID 仍可能留在 Lumi。
   - 後續需明確選擇：維持單向並顯示說明，或建立雙向衝突規則；不可模糊處理。

4. **刪除同步失敗會留下無法重試的外部孤兒**
   - 現況會刪本機資料並提示外部可能尚存，但 link 同時消失。
   - 後續應加待刪除佇列或讓使用者選擇「只刪 Lumi／保留並稍後重試」。

## P1：每天都會遇到的操作摩擦

1. **行程無法跨日或過夜**
   - DB 已有開始／結束日期，但 v0.4.70 表單固定同一天。
   - v0.4.71 已加入開始／結束日期、同日／隔天快捷與跨日驗證。

2. **日期與時間全靠手打**
   - 容易輸入錯誤，也無法在 10 秒內完成。
   - v0.4.71 第一階段：任務加入今天／明天／無日期；行程預設時間改為今天的下一個半小時，加入 30 分／1 小時／2 小時快捷。
   - 後續：採平台日期／時間選擇器，文字仍保留給熟練使用者。

3. **不同來源行程沒有按時間合併**
   - v0.4.70 先列全部 Lumi 行程，再列全部外部行程，會破壞一天的時間順序。
   - v0.4.71 已改為全天優先，其餘 Lumi／外部行程合併後按開始時間排列，並顯示結束時間。

4. **沒有快速改期／複製**
   - 常見情境是「移到明天」「延後一週」「複製上次課程」。
   - 建議先做任務快速改到今天／明天／週末，以及行程複製後修改；之後再做拖曳。

5. **提醒只有行程有，而且未連動時不會真的通知**
   - 產品模型已決定提醒是任務／行程屬性，但任務 schema 尚無時間與提醒。
   - 後續需加入本機通知層，讓未連動 Google 日曆也能提醒；不能只依賴手機日曆。

## P1：資訊架構缺口

1. **只有月視圖＋選定日清單**
   - 月視圖適合概覽，不適合找空檔或看重疊。
   - 建議下一階段新增 Schedule 清單，再做單日／三日時間軸；手機上週視圖不必優先於 Schedule。

2. **沒有行事曆搜尋**
   - 無法找回過去或未來的任務、Lumi 行程與外部行程。
   - 建議先做 Lumi 本地跨任務／行程搜尋；外部內容再依系統 API 能力限制日期範圍。

3. **只能讀取選定的單一寫入日曆**
   - 使用者可能把工作、私人、生日分在不同日曆，目前 Lumi 看不完整。
   - 正確模型應分開：
     - 一個「Lumi 寫入日曆」。
     - 多個「顯示中的外部日曆」。
   - 需要設定格式 migration 與多日曆顏色／顯示開關，排在重複規則之後。

4. **任務與行程分類共用，但管理入口不一致**
   - 任務可建立自訂分類，行程只能使用既有分類。
   - 後續應抽出共用分類管理，不在兩個表單各做一套。

## P2：成熟後再做

- 重複事件／任務：每日、每週、每月、每年、自訂、結束條件，以及「只改這次／之後／全部」。
- 自然語句建立：例如「明天下午三點開會一小時，提前 30 分提醒」。
- 範本：課程、運動、繳費、固定會議。
- 忙碌／有空、私人、邀請人與會議回覆。
- 地點搜尋、行程時間與出發提醒。
- 時區與旅行模式。

2. v0.4.72：本機提醒基礎＋任務時間／提醒。
3. v0.4.73：Schedule 視圖＋跨任務／行程搜尋＋快速改期／複製。
4. v0.4.74：重複規則與系列編輯。
5. v0.4.75：多個顯示日曆、一個寫入日曆、同步狀態與重試佇列。
