### 財務進階規劃（朋友回饋，待實作）

**儲蓄目標系統：**
- 使用者設定「一個月打算存多少」→ 從收入先扣除
- 固定必要支出（房租、水電、瓦斯等）讓使用者先輸入 → 也先扣除
- 剩下的錢用比例分配到各類別（餐飲/興趣/交通/其他）→ 自動設上限
- 超過上限 → 提醒
- 水電瓦斯等特殊消費要額外分類設定

**長期儲蓄目標：**
- 設定「幾個月/幾年內存多少」→ 用過去幾個月平均開銷反推每月該存多少
- 問題：需至少一個月數據才能計算

**收入分類：**
- 固定收入（薪水）vs 額外收入（股票、發票中獎等）
- 額外收入進來時詢問使用者：歸到哪個類別（餐飲/興趣/交通/其他）還是存起來
- 存起來 → 放到「已存金額」區域，不列入開支計算
- 歸到某類別 → 該月份該類別上限提高

**緩衝區機制：**
- 沒特別安排的額外收入 → 進緩衝區
- 緩衝區可抵掉任何類別超標的花費
- 作為最後警告線

**不固定收入處理：**
- 扣掉想存的錢後，用類似定期定額方式從可用餘額扣款
- 扣的部分列入已存金額

**分析：** 維持現有 Gemini 分析不變
